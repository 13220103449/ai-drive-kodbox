# AI Drive v0.6.0

## 挂载盘伪回收站

- Agent 调用 `delete` 时不再真正删除文件或文件夹。
- 系统在当前挂载存储根目录自动建立 `AI Drive回收站(勿删)`，并按日期、Agent 和删除批次归档。
- 新增 `trash` 与 `restoreTrash`，可查询软删除记录并恢复到原路径。
- 普通 Agent 文件列表不会显示保护目录，Agent 也不能通过常规文件 API 修改保护目录。
- 不提供 Agent 永久删除接口，归档内容默认永久保留。

## 挂载盘历史版本

- `write`、`upload`、`uploadChunk` 覆盖文件前，旧内容复制到 `AI Drive历史版本(勿删)`。
- 版本恢复前也会先保存当前内容，因此恢复操作可以再次撤销。
- 历史版本保存在百度网盘等当前挂载存储中，不再受到 NAS 本地版本空间限制。
- 兼容恢复 v0.5.0 及以前生成的本地历史版本。

现有 Agent 账号、Token、网盘文件和存储挂载配置均保持不变。
