# AI Drive v0.9.0

- **百度网盘实时镜像（本版核心）**：真人用户（默认 `admin`，可配置，如 `admin,sbuxcn`）的本地存储文件自动镜像到百度网盘「AI-Drive镜像/<用户名>/」目录；智能体部门共享空间同样纳入镜像。严格单向：**只上传到百度，绝不把百度内容下载回服务器存储**。
- **删除=进百度回收站**：本地删除（前台消失）时，百度副本自动移入「AI-Drive镜像回收站/<用户名>/<原路径>」——在百度网盘 App 里人眼可见、可手动找回；本地恢复则移回镜像原位。百度侧永不物理删除。
- **容灾读取**：Agent API 读取部门共享空间时，若本地文件缺失/损坏，自动从百度镜像副本**流式中转**给请求者（不落盘到服务器）。
- **排除范围**：`AI Drive回收站(勿删)`、`AI Drive历史版本(勿删)`（任意层级）不入镜像；已存储在其他网盘（ioType≠本地）的内容自动跳过——不重复上传。
- **可靠性**：镜像走独立队列表（失败指数退避重试，默认 5 次），**百度失败绝不阻塞本地正常使用**；每轮 worker 消费批处理，定时对账（默认 60 分钟）兜底捕捉漏单与删除。
- **管理面板**：新增「百度镜像」按钮——同步统计（已同步/排队/失败/已删除）、扫描差异、立即处理、重试失败项、设置镜像用户。
- **修复 0.7.0 遗留缺陷**：`queue-worker.php` 每分钟 cron 失败（`runQueuedUploads` 方法缺失）——worker 已重写为镜像队列入口；管理面板两个死按钮（上传任务/应用备份，后端端点不存在）已移除。
- **前提**：百度网盘存储驱动已挂载且完成 OAuth 授权（存储管理中的 Baidu 存储）；baiduDisk 插件保持启用（token 自动续期）。
- 升级说明：从 0.8.0 在线更新即可。升级后在管理面板「百度镜像」中点「扫描差异并排队」完成首扫，worker 每分钟自动消费队列。
