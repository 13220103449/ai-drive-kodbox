# AI Drive v0.3.3

## 关键修复

- 修复群晖访问 `8091` 时返回空白页面的问题。
- 恢复 KodBox 原始启动数据文件；此前 Git 换行转换使该文件发生 1 字节变化，触发完整性检查后静默退出。
- 将启动数据文件明确标记为二进制，避免后续检出、合并和发布时再次被转换。
- 保留 v0.3.2 的 PHP 8.2 `zlib` 扩展修复和独立端口 `8091`。

## 升级

请在群晖套件中心手动上传 `AI-Drive-0.3.3-0004-noarch.spk` 覆盖安装。用户文件和数据库会保留。

安装完成后访问：`http://NAS_IP:8091/`。

- `AI-Drive-0.3.3-0004-noarch.spk`：群晖 DSM 7 空白页修复包。

- `ai-drive-update-v0.3.3.zip.sha256`：在线更新包 SHA-256 校验值。
