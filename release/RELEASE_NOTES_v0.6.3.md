# AI Drive v0.6.3

## Agent 接入完整性

- MCP 删除说明明确为“移入可恢复回收站”，不再错误宣称永久删除。
- MCP 写入和上传自动创建缺失的目标父目录；写入成功前检查远端大小并读回计算 SHA-256，校验失败会向 Agent 返回错误。
- MCP 下载在保存前用远端 `stat` 校验文件大小。
- 新增 MCP 模拟服务验收，覆盖 700 KiB 二进制上传、自动创建目录、SHA-256 读回及校验失败处理。
- Agent API 验收增加大二进制上传、覆盖和读回 SHA-256 检查。

## 备份边界透明化

- 元数据快照加入软删除记录，并明确快照不包含 KodBox 全库、文件正文或挂载云盘内容。
- 管理后台及使用指南说明完整灾难恢复仍需备份 Docker 数据目录、外部数据库和部署配置；挂载云盘数据由对应存储自身保护。
- 不改变 Agent 的软删除策略；回收站内容仍可恢复，不开放永久删除。
