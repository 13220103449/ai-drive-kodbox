# AI Drive v0.6.5

## 修复挂载存储历史版本恢复

- 恢复前先分块读取历史版本并验证大小和 SHA-256，校验失败不覆盖当前文件。
- 使用 KodBox 正常上传覆盖接口，不再先删除当前 source 再复制、重命名，避免恢复失败后原路径消失。
- 写入后读回验证；失败时尝试恢复事先保留的当前内容。如果存储故障使回退也失败，保留本地恢复副本并记录其位置。
- 新增不透明 source ID、拒绝写入、写入损坏、写入异常、历史内容损坏和空文件回归测试。

## 修复 WebDAV 百度网盘下载

- WebDAV 完成身份认证后，使用与 Agent REST API 相同的递归驱动加载器，再解析文件路径。
- 更新包包含 WebDAV 兼容文件，保留 personal / department 空间别名。
- 新增真实 WebDAV 分发路径的驱动加载测试。

## 验收

- 在线验收脚本增加历史版本恢复与读回 SHA-256，并支持通过环境变量传入 WebDAV 凭据测试文件下载。
- 发布流程在任一回归测试失败时立即停止。
