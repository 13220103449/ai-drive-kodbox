# AI Drive v0.3.6

## 关键修复

- 修复群晖安装环境检测中 `data/system` 目录权限显示红叉的问题。
- 数据目录现在允许 AI Drive 套件用户与 Web Station `http` 组读写，并拒绝其他系统用户访问。
- 每次安装和升级都会递归修复已有数据目录的所有者、组和读写权限。
- 迁移旧数据时不再保留错误的原始所有者信息。
- 包含 v0.3.5 的完整前端资源、8091 独立端口和 PHP `zlib` 配置。

## 升级

请在群晖套件中心手动上传 `AI-Drive-0.3.6-0007-noarch.spk` 覆盖安装，无需卸载旧版本。

安装完成后访问：`http://NAS_IP:8091/`，目录权限应显示绿色通过。

## 发布文件

- `AI-Drive-0.3.6-0007-noarch.spk`：群晖 DSM 7 数据目录权限修复包。
- `ai-drive-update-v0.3.6.zip`：AI Drive 插件在线更新包。
- `ai-drive-update-v0.3.6.zip.sha256`：在线更新包 SHA-256 校验值。
