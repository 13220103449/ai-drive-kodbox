# AI Drive v0.3.5

## 关键修复

- 修复群晖安装页面变灰、环境检测不运行、所有项目无法点击的问题。
- 恢复缺失的 KodBox 前端运行文件 `vendor.js`、`api.js` 和 `main.js`。
- 修正 Git 发布归档规则，只排除仓库根目录的构建产物，不再误删程序内部的 `dist` 与 `data` 目录。
- 发布构建新增必需文件检查，缺少前端运行文件、启动文件或更新器 CA 证书时将直接终止打包。
- 保留 8091 独立端口、PHP `zlib` 扩展和升级后强制同步运行目录功能。

## 升级

请在群晖套件中心手动上传 `AI-Drive-0.3.5-0006-noarch.spk` 覆盖安装，无需卸载旧版本。

安装完成后访问：`http://NAS_IP:8091/`。

## 发布文件

- `AI-Drive-0.3.5-0006-noarch.spk`：群晖 DSM 7 完整前端资源修复包。
- `ai-drive-update-v0.3.5.zip`：AI Drive 插件在线更新包。
- `ai-drive-update-v0.3.5.zip.sha256`：在线更新包 SHA-256 校验值。
