# AI Drive v0.3.0

首个可安装版本，基于 KodBox 1.69.03。

## 新增

- 自动创建“智能体”部门和真实 Agent 网盘账号。
- Agent 个人空间与智能体部门共享空间。
- 上传、下载、读取、覆盖、移动、复制、重命名、删除和分享文件 API。
- WebDAV 与 MCP 接入。
- 创建智能体后的单次凭据弹窗及一键复制接入话术。
- 管理后台 GitHub Release 在线更新，包含 SHA-256 校验、更新前备份和失败回滚。
- DSM 7 群晖 Web Station 安装包。

## 安装包

- `ai-drive-update-v0.3.0.zip`：后台在线更新包。
- `ai-drive-update-v0.3.0.zip.sha256`：更新包校验值。
- `AI-Drive-0.3.0-0001-noarch.spk`：群晖 DSM 7 安装包。

群晖版安装前需在套件中心安装 Web Station 和 PHP 8.2。
