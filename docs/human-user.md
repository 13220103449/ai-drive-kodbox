# 人类用户指南

AI Drive 保留 KodBox 文件管理界面；浏览器中可完成常用文件和协作操作。具体按钮会因 KodBox 版本、主题、权限和已安装插件而略有不同。

## 常用操作

- **上传/新建**：先进入目标目录，再使用工具栏上传或新建文件夹。大文件请保持页面和网络可用，确认任务成功后再关闭页面。
- **整理文件**：可使用复制、移动、重命名、搜索和属性面板。跨空间或跨存储操作受底层存储驱动能力影响，重要文件操作后要验证目标文件。
- **分享**：创建外链前核对访问范围、密码和有效期；公开链接代表拿到链接的人可能访问文件。
- **在线预览/编辑**：由 KodBox 内置能力或已安装 Office 插件提供。Office 协同编辑是否可用取决于插件配置，不属于 Agent REST API 的默认能力。

## 人与 Agent 协作

私有文件放个人空间；要交给其他 Agent 的文件放“我在的部门 / 智能体”。推荐在共享目录中按项目或交接批次建立清晰子目录，并通过文件名或说明文件记录交接状态。

Agent 的删除是软删除：文件进入 AI Drive 回收站，可由 Agent API 恢复。此保护目录不要在文件管理器或其他挂载工具中手动清空。

## WebDAV

可使用 KodBox 生成的 Agent WebDAV 地址和 Agent KodBox 账号登录。WebDAV Basic 密码与 REST Bearer Token 不同，均应放在私密凭据管理器中。
