# 存储挂载与兼容性

## 空间与驱动

Agent 有 `personal`（个人空间）和 `department`（智能体部门）两种空间。空间背后的物理存储由 KodBox 的用户/部门默认存储与管理员挂载配置决定；不是每个 Agent API 调用都能任意选择一个物理网盘。

AI Drive 会发现已安装的可选 KodBox 存储驱动，并在 `capabilities.storageDrivers` 中报告已加载的驱动信息。驱动已加载只代表类可用，不代表其所有写入、覆盖、移动或恢复功能都通过验证。

## 操作能力检查表

为每个实际挂载点分别跑一遍 [Agent API 验收脚本](../AGENT_GUIDE.md#7-发布后的自动验收)，不要把“另一个百度账号/另一个网盘驱动测过”当成当前挂载点已验证。

| 能力 | 验证方法 | 未验证前的处理 |
| --- | --- | --- |
| 目录/文件列表 | `mkdir` → `list` → `stat` | 不把空列表当作上传成功 |
| 上传与覆盖 | 上传新文件及同名文件 | 覆盖前核实历史版本 |
| 下载完整性 | `stat` 后下载并对比 SHA-256 | 校验不一致即失败，不归档成功 |
| 移动/复制 | 建立多级目标目录并分别测试 | 暂时使用已验证的 API 操作 |
| 软删除/恢复 | 删除临时文件后 `trash` → `restoreTrash` | 不在真实资料上首次试验 |
| 历史版本 | 覆盖临时文件后 `versions` → `restore` | 不默认推断驱动一定支持 |
| 分享 | 分享临时子目录并验证链接/权限 | 先确认链接访问范围 |

### 已知实测范围

AI Drive v0.6.2 曾在用户提供的百度网盘挂载环境中完成 API 主要文件链路验收；该结果只适用于当时的站点、账号、挂载和版本组合。换挂载账号、KodBox/驱动版本或目标空间后，仍应重跑验收。

## 保护目录

AI Drive 会在相应挂载存储根部使用 `AI Drive回收站(勿删)` 和 `AI Drive历史版本(勿删)` 保存保护内容。它们不应被手动移动或清空。更多行为和恢复步骤见[回收站与历史版本](recycle-and-versions.md)。
